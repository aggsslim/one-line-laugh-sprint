One original funny line about everyday life, written for make.fun's One-Line Laugh Sprint ($5 pool). A tiny deterministic Python program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
cat output/entry.txt
```
